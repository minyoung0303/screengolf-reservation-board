## 1. 개요

전화 예약 접수 시 직원 입력값(시간 · 인원 · 게임 수)만으로 종료 시각 자동 계산 및 배정 가능 타석 즉시 제시.
**직원 전용 프로그램**, 손님 접근 경로 없음.

| 항목 | 내용 |
|---|---|
| 사용자 | 매장 직원 (카운터 전화 응대 담당) |
| 사용 환경 | 직원용 데스크톱 PC (Windows 10) 1대 + 폰·태블릿 보조 |
| 배포 방식 | 설치파일(.exe) 실행 |
| 인터넷 | 불필요 (매장 인터넷 장애 시에도 동작) |
| 손님 접근 | 없음 |
| 비용 | 개발비 0원 · 운영비 0원 |

## 2. 해결하려는 문제

현행 방식: 수기 장부 기록. 통화 중 직원 암산 부담 2가지.

| 부담 | 내용 |
|---|---|
| 종료 시각 계산 | "2시에 2명 2게임" → 소요 2시간 → 16:00 종료 |
| 빈자리 대조 | 10개 타석 × 하루 12시간 30분 중 해당 구간 공실 확인 |

- 통화 중 수 초 내 처리 요구 → 계산 지연 → **예약 중복 발생**
- 핵심 과제: 화면 설계가 아닌 **소요시간 계산 + 중복 판정**

> **성공 기준**
> 전화 응대 직원의 **3초 내** 응답 가능 여부.
> ("가능합니다" 또는 "그 시간은 마감이라 O시는 어떠세요")

## 3. 매장 운영 규칙 (확정값)

| 항목 | 값 |
|---|---|
| 타석(방) 수 | 10개 |
| 타석당 최대 인원 | 6명 (전 타석 동일, 1~6명) |
| 영업 시간 | 08:30 ~ 21:00 (12시간 30분) |
| 마지막 입장 | 21:00 |
| 예약 사이 여유 시간 | 10분 |
| 워크인(현장 손님) | 예약과 동일 기록 |

## 4. 소요시간 계산 규칙

```
소요시간 = 인원 × 게임 수 × 30분
점유시간 = 소요시간 + 10분(정리·여유)
```

확인된 기준: 1명 2게임 = 1시간 / 2명 2게임 = 2시간 → **1인 1게임 30분**

### 계산 결과표 (점유시간, 여유 10분 포함)

| 인원 \ 게임 | 1게임 | 2게임 | 3게임 |
|---|---|---|---|
| 1명 | 40분 | 1시간 10분 | 1시간 40분 |
| 2명 | 1시간 10분 | 2시간 10분 | 3시간 10분 |
| 3명 | 1시간 40분 | 3시간 10분 | 4시간 40분 |
| 4명 | 2시간 10분 | 4시간 10분 | 6시간 10분 |
| 5명 | 2시간 40분 | 5시간 10분 | 7시간 40분 |
| 6명 | 3시간 10분 | 6시간 10분 | 9시간 10분 |

> ⚠️ **검증 필요 구간: 4~6명**
> - 공식 적용 시 6명 2게임 6시간 / 3게임 9시간 → 영업시간의 1/2 ~ 3/4 점유
> - 실제 소요시간 단축 여부 실측 필요
> - 미검증 상태로 방치할 경우 **공실 시간대를 프로그램이 차단하는 오류** 발생
> - 대응: 인원별 1인 1게임 시간을 **개별 설정값으로 분리** (초기값 전 인원 30분)
> - 보정 절차: 시범운영 2주간 실제 종료 시각 기록 → 인원별 값 조정
> - 개별 예약은 수동 조정 가능 (+30분 / −30분 / +1게임)

### 마감 시간 처리

- 21:00 입장 시 종료가 영업 종료 초과 가능 (예: 2명 2게임 → 23:10 종료)
- 정책: **저장 허용 + 경고 표시**. 차단하지 않음 (수용 여부는 직원 판단 사항)

- 현재 시각선 표시 + 화면 진입 시 현재 시각 위치 자동 스크롤

- 날짜 이동: 어제 ← 오늘 → 내일, 달력 직접 선택
- 빈칸 클릭 → 해당 타석·시간으로 등록창 즉시 개방
- 블록 드래그 → 시간·타석 이동 (겹침 시 거부)

### 5.2 예약 등록 (전화 응대 동선)

입력 항목 4개로 축소. 이름·연락처 미입력 저장 허용.

| 순서 | 입력 | 방식 |
|---|---|---|
| 1 | 시작 시각 | 30분 단위 버튼 + 직접 입력 |
| 2 | 인원 | 1~6 버튼 |
| 3 | 게임 수 | 1~5 버튼 |
| 4 | 이름 / 연락처 / 메모 | 선택 입력 |

입력 즉시 판정 결과 표시.

- 가능: `→ 14:00 ~ 16:10 (2시간 10분) · 배정 가능 타석: 3번, 5번, 7번`
- 불가: `→ 14:00은 10개 타석 마감` + **대안 시각 3개 자동 제시**
- 시간 버튼 색상으로 해당 조건의 가능 여부 사전 표시

대안 추천 로직

- 요청 시각 기준 30분 단위 전후 탐색 → 가능 시각 근접 순 3개 추출
- 목적: 통화 중 "그 시간은 찼는데 O시는 어떠세요" 즉시 응답

## 6. 데이터 구조

| 테이블 | 내용 |
|---|---|
| `rooms` | 타석 번호·이름·정원·사용 여부 |
| `reservations` | 타석, 이름, 연락처, 인원, 게임 수, 시작·종료 시각, 여유시간, 워크인 여부, 상태, 메모 |

- 저장 위치: `%APPDATA%\yeyakbo\data.db` (SQLite 파일 1개)
- 상태값: 예약 / 이용중 / 완료 / 노쇼 / 취소
- 중복 검사 대상: 예약 · 이용중 · 완료 (노쇼 · 취소는 공실 처리)

## 7. 중복 방지 로직 (핵심)

```
겹침 조건:  기존.시작 < 신규.종료  AND  기존.종료 > 신규.시작
(취소·노쇼 상태 제외. 끝과 시작이 맞닿는 경우는 겹침 아님)
```

- 검사 + 저장을 **단일 트랜잭션**으로 처리 → 2개 기기 동시 저장 시 1건만 성공
- 화면 검증에 의존하지 않고 **저장 단계에서 차단**. 이 프로그램의 존재 이유
- 시간 표현은 **자정 기준 분(정수)** 통일 (`08:30` → `510`) → 소수점·시간대 오류 원천 제거

## 8. 기술 구성

| 구분 | 선택 | 비용 | 근거 |
|---|---|---|---|
| 앱 형태 | Electron (Windows 데스크톱) | 무료 | 설치파일 단일 배포 + 동일 프로세스에서 폰 접속용 서버 구동 |
| 데이터 | `node:sqlite` (Node 24 내장) | 무료 | 네이티브 모듈 컴파일 제거 → 타 PC 설치 시 빌드 도구 요구 없음 |
| 서버 | `node:http` | 무료 | 프레임워크 미사용, 라우터 자체 구현 → 번들 실패 지점 제거 |
| 실시간 동기화 | SSE (`EventSource`) | 무료 | 단방향 전파에 충분. WebSocket 라이브러리 불필요 |
| 화면 | React + TypeScript + Vite | 무료 | 타임라인 UI 구현 속도 |
| 패키징 | electron-builder (NSIS) | 무료 | 코드 서명 미사용 → 첫 실행 경고 1회 수용 |

- **런타임 의존성 0개.** 배포물은 번들된 `dist` 뿐
- 서버·클라우드 미사용 → 월 비용·인터넷 장애·계정 관리 제거

## 9. 폰 / 태블릿 접속 방안

```
   [직원 데스크톱 PC]  ← 데이터 원본, 영업 중 상시 실행
          │  매장 와이파이
   ┌──────┼──────┐
 [태블릿] │  [직원 폰]     브라우저 접속 (앱 설치 없음)
```

| 항목 | 내용 |
|---|---|
| 설치 | 불필요. 주소 접속 후 홈 화면 추가 시 앱과 동일하게 동작 |
| 지원 | 안드로이드(크롬) · 아이폰·아이패드(사파리) 모두 |
| 조건 | 데스크톱 PC와 동일 와이파이 + PC 전원 켜짐 |
| 최초 1회 | Windows 방화벽 "개인 네트워크 허용" |
| 접속 편의 | 카운터 화면에서 **QR 코드** 생성 → 카메라 촬영으로 접속 |
| 동기화 | 한쪽 변경 시 다른 기기 화면 즉시 갱신 |
| 폰 화면 | 세로 화면용 리스트형 + 시간대별 잔여 타석 요약 (가로 격자는 폰에서 판독 불가) |
| 비용 | 0원 |

> 🔒 **접근 제어 필수 조건**
> - 매장 와이파이를 손님과 공용 → 주소 인지 시 누구나 접속 시도 가능
> - 손님 연락처 노출 위험 → **PIN 잠금 필수 적용**
> - 카운터 PC(loopback)는 PIN 없이 사용, 폰·태블릿은 PIN 확인 후 사용
> - PIN: scrypt 해시 저장, 숫자 4~8자리, 취약 패턴(`0000`·`1234`) 거부
> - 시도 제한: 5회 실패 1분 → 10회 5분 → 15회 30분 잠금
> - PIN 변경·재설정은 카운터 PC 전용. 변경 시 전체 원격 세션 해제
> - 한계: 매장 내부 HTTP 통신 미암호화 → 중요 비밀번호를 PIN으로 사용 금지 (매뉴얼 명시)

### 매장 외부 접속 (2차 검토)

- 클라우드 배포 필요. 무료 요금제로도 가능하나 로그인·계정 관리 추가 발생
- 무료 정책 변경 리스크 존재
- 1차 범위 제외. 실제 수요 확인 후 재검토

## 10. 설치 및 배포

| 단계 | 내용 |
|---|---|
| 1. 전달 | 설치파일 약 95MB. 카톡·USB·OneDrive 링크 |
| 2. 설치 | 파일 실행 → 설치 → 바탕화면 아이콘 생성 |

| 4. 초기 설정 | 타석 10개·영업시간 기본값 적용 상태로 즉시 사용 |
| 5. 방화벽 | 폰·태블릿 사용 시 "개인 네트워크 허용" 1회 |
| 6. 업데이트 | 새 설치파일 실행. 예약·설정·PIN 유지 (데이터 폴더 분리 저장) |

- 설치 매뉴얼: 그림 포함 A4 문서 별도 작성
- 직원 배포용 1장 안내 별도 작성 (폰 접속 전용)

### 1차 릴리즈 — 데스크톱 (12일 작업 / 달력 3~4주)

| | **소계** | **12일** |
