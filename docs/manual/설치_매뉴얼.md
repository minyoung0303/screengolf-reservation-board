# 예약보드 설치 · 사용 매뉴얼

버전 1.0.3 · Windows 10 이상 · 직원용

> **이미 이전 버전(1.0.0 / 1.0.1 / 1.0.2)을 설치해서 쓰고 있다면** 새 설치파일을 그냥 실행하면 돼요.
> 저장한 예약·설정·PIN은 그대로 남습니다. 자세한 내용은 4번 항목의 "새 버전으로 바꿀 때" 를 봐주세요.

---

## 1. 설치하기 (5분)

> ### ⚠ 설치파일(exe)은 카운터 컴퓨터에만 설치해요
>
> **폰과 태블릿에는 설치하지 않아요.** 안드로이드·아이폰에서는 exe 파일이 실행되지 않습니다.
> 폰·태블릿은 설치 없이 **주소로 접속**해서 써요 (3번 항목 또는 `폰_태블릿_접속방법.pdf` 참고).
>
> 정리하면 이렇습니다.
>
> | 기기 | 방법 |
> |---|---|
> | 카운터 컴퓨터 (Windows) | 설치파일로 설치 |
> | 직원 폰 · 태블릿 (안드로이드/아이폰) | 설치 없음. 브라우저로 주소 열기 |

### 준비물

- 카운터 컴퓨터 (Windows 10 이상)
- 설치파일 `YeyakBo-Setup-1.0.3.exe`

### 설치파일 받는 곳

아래 주소를 열면 받으실 수 있어요.

**https://github.com/minyoung0303/screengolf-reservation-board/releases/latest**

페이지 아래쪽 **Assets** 항목에 있는 `YeyakBo-Setup-1.0.3.exe` 를 눌러서 받아요.
파일을 따로 전달받으셨다면 그걸 쓰셔도 됩니다. 같은 파일이에요.

### 순서

**1) 설치파일 실행**

받은 `YeyakBo-Setup-1.0.3.exe` 를 두 번 클릭해요.

**2) 파란 경고창이 뜨면 → 추가 정보 → 실행**

```
┌────────────────────────────────────────┐
│  Windows의 PC 보호                      │
│                                        │
│  Microsoft Defender SmartScreen에서    │
│  인식할 수 없는 앱의 시작을 차단했습니다.  │
│                                        │
│         [추가 정보]  ← 여기 클릭         │
│                              [실행 안 함]│
└────────────────────────────────────────┘
                 ↓
         [실행]  ← 그 다음 여기 클릭
```

바이러스가 아니에요. 프로그램에 유료 인증서(연 15~40만원)를 붙이지 않아서 나오는 안내예요.
아는 사람이 만든 프로그램이라 인증서 비용을 아꼈어요.

**3) 설치 위치는 그대로 두고 [설치]**

설치가 끝나면 바탕화면에 **예약보드** 아이콘이 생겨요.

**4) 방화벽 창이 뜨면 → "개인 네트워크" 체크 → [액세스 허용]**

```
┌────────────────────────────────────────┐
│  Windows Defender 방화벽                │
│  이 앱의 일부 기능이 차단되었습니다        │
│                                        │
│  ☑ 개인 네트워크(가정 또는 직장 네트워크) │
│  ☐ 공용 네트워크                        │
│                                        │
│       [액세스 허용]      [취소]          │
└────────────────────────────────────────┘
```

이걸 허용해야 **폰·태블릿에서 접속**할 수 있어요. 실수로 취소했다면 프로그램을 지우고 다시 설치하면
다시 물어봐요. (또는 Windows 방화벽 설정에서 예약보드를 허용)

**5) 첫 실행 → PIN 정하기**

처음 켜면 PIN(잠금번호)을 정하는 화면이 나와요. 숫자 4~8자리로 정해주세요.
자세한 내용은 **PIN_안내.md** 를 봐주세요.

**6) 끝. 예약판이 열려요**

타석 10개, 영업시간 08:30~21:00, 1인 1게임 30분, 정리시간 10분이 기본으로 들어가 있어요.
바꾸려면 오른쪽 위 **설정** 을 누르세요.

## 2. 매일 쓰는 방법

### 전화로 예약을 받을 때

오른쪽 위 **+ 예약 등록** (또는 예약판의 빈 곳을 클릭)

```
1. 시작 시각  [08:30][09:00][09:30] ... 누르기
2. 인원       [1명][2명][3명][4명][5명][6명]
3. 게임 수    [1게임][2게임][3게임][4게임][5게임]

   → 14:00 ~ 16:00 · 2시간          (자동 계산)
     배정할 타석 (7석 가능)
     [자동] [1번] [3번] [5번] ...
```

- 시간 버튼의 **진한 테두리** = 그 조건으로 자리가 있는 시간
- **흐린 점선** = 그 시간은 자리가 없음
- 타석은 **자동**으로 두면 알아서 빈 곳에 넣어요
- 이름·연락처·메모는 안 넣어도 저장돼요. 통화 중이면 시간만 잡고 나중에 채워도 돼요
- `Ctrl + Enter` 로도 저장돼요

### 그 시간이 다 찼을 때

빨간 글씨로 이렇게 나와요.

```
14:00에는 10개 타석이 모두 차 있어요.

이 시간은 어떠세요?
[13:00 3석]  [16:30 5석]  [17:00 8석]
```

손님에게 그대로 읽어주면 돼요. 버튼을 누르면 그 시간으로 바뀌어요.

### 예약 없이 온 손님 (워크인)

오른쪽 위 **워크인** 버튼. 지금 시각으로 바로 등록돼요. 예약판에서 주황색으로 표시돼요.

### 손님이 도착하면

예약판에서 그 블록을 누르고 **도착 (체크인)**. 블록이 초록색으로 바뀌어서 지금 이용 중인 팀이
한눈에 보여요. 목록 탭에서는 **체크인** 버튼 한 번으로 처리할 수 있어요.

### 시간이 늘어나거나 줄어들 때

블록을 누르고 **+30분 / -30분 / +1게임**. 뒤 예약과 겹치면 저장되지 않고 알려줘요.

### 예약을 옮길 때

예약판에서 블록을 **끌어서** 다른 시간·다른 타석으로 옮길 수 있어요. 겹치는 자리에 놓으면
옮겨지지 않고 이유를 알려줘요.

### 취소 · 노쇼

블록을 누르고 **예약 취소** 또는 **노쇼**. 기록은 남고 자리는 다시 비어요.
예약판에서 보고 싶으면 위쪽 **취소·노쇼 표시** 를 체크하세요.

### 손님 찾기

**검색** 탭에서 이름이나 **전화 뒷자리**로 찾아요. (예: `5678`)

### 종이로 뽑아두기

**인쇄** 탭 → **인쇄하기**. A4 한 장으로 오늘 예약이 나와요.
프로그램이 안 켜지거나 정전일 때를 대비해 하루 한 번 뽑아두면 마음이 편해요.

### 예약판 읽는 법

| 색 | 뜻 |
|---|---|
| 파랑 | 예약 (아직 안 옴) |
| 초록 | 이용중 (체크인함) |
| 주황 | 워크인 (예약 없이 온 손님) |
| 회색 | 이용 완료 |
| 점선 흐림 | 취소·노쇼 |
| 블록 끝 사선 무늬 | 정리 시간 10분 |
| 회색 사선 구역 | 영업 종료(21:00) 이후 |
| 빨간 세로선 | 지금 시각 |

## 3. 폰 · 태블릿에서 보기 (설치 없음)

폰·태블릿에는 **아무것도 설치하지 않아요.** 브라우저로 주소를 한 번 열면 끝이에요.
직원들에게는 이 항목만 따로 정리한 `폰_태블릿_접속방법.pdf` 를 보내주면 편해요.

조건은 두 개예요. 카운터 컴퓨터가 **켜져 있어야** 하고, 폰과 컴퓨터가 **같은 와이파이**에 있어야 해요.

### 처음 연결할 때 (QR 코드가 제일 편해요)

1. 컴퓨터에서 예약보드 오른쪽 위 **폰 연결** 버튼을 눌러요
2. QR 코드가 크게 나와요
3. 폰 **카메라 앱**으로 그 QR을 찍고, 뜨는 주소를 눌러요
4. PIN 입력 → 예약판 열림

주소를 직접 입력해도 돼요. **폰 연결** 창이나 **설정** 탭에 `http://192.168.0.10:5180` 같은 주소가
적혀 있어요. 검색창이 아니라 **주소창**에 넣어주세요.

### 홈 화면에 앱처럼 두기 (아이폰 · 안드로이드 모두 됩니다)

앱스토어나 플레이스토어에서 받을 건 없어요. 주소를 한 번 열고 홈 화면에 올려두면 끝이에요.

**아이폰 · 아이패드 (사파리)**

1. 사파리로 접속 주소를 열어요 (크롬이 아니라 **사파리**로 해야 홈 화면 추가가 돼요)
2. 아래쪽 **공유 버튼** (□ 위에 ↑ 있는 아이콘)
3. 목록을 내려서 **홈 화면에 추가**
4. 이름이 `예약보드` 로 나오면 오른쪽 위 **추가**

**안드로이드 (크롬)**

1. 크롬으로 접속 주소를 열어요
2. 오른쪽 위 **⋮** 버튼
3. **홈 화면에 추가** (또는 **앱 설치**)
4. **설치** 또는 **추가**

이렇게 하면 파란색 예약보드 아이콘이 홈 화면에 생기고, 누르면 **주소창 없이 앱처럼** 열려요.
매번 주소를 입력하지 않아도 되고, PIN도 기억하고 있어서 바로 예약판이 나와요.

### 폰에서 알아두면 좋은 것

| 상황 | 설명 |
|---|---|
| 아이폰에서 크롬으로 열면? | 보는 건 되지만 홈 화면 추가가 안 돼요. 사파리를 쓰세요 |
| 오랫동안 안 쓰면 | 1~2주 넘게 안 열면 PIN을 다시 물어볼 수 있어요. 한 번 넣으면 다시 기억해요 |
| 접속 주소가 바뀌면 | 홈 화면 아이콘도 다시 만들어야 해요. 공유기에서 고정 IP를 주면 계속 같은 주소를 써요 |
| 아이패드 | 화면이 넓으면 컴퓨터와 같은 예약판(가로 시간표)이 나와요. 블록을 끌어서 옮기는 것도 돼요 |
| 데이터 요금 | 매장 와이파이 안에서만 통신해서 데이터가 들지 않아요 |

### 폰 화면에서 할 수 있는 것

- **시간표**: 시간대별 남은 타석 수. 누르면 그 시간으로 예약 등록
- **예약 목록**: 오늘 예약을 카드로 보기, 체크인·완료 처리
- **찾기**: 이름·전화 뒷자리로 검색
- 오른쪽 아래 **+ 예약** 으로 등록

카운터 컴퓨터와 **같은 데이터**를 봐요. 한쪽에서 예약을 잡으면 다른 쪽 화면도 바로 바뀌어요.

### 접속이 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 페이지가 안 열림 | 폰이 매장 와이파이에 붙어 있는지 (LTE·5G로 빠지면 안 돼요) |
| 아이폰에서 "안전하지 않은 연결" 안내 | 매장 안에서만 쓰는 주소라 정상이에요. 그냥 계속 진행하면 돼요 |
| 여전히 안 열림 | 카운터 컴퓨터가 켜져 있고 예약보드가 실행 중인지 |
| 그래도 안 열림 | 설치할 때 방화벽 "개인 네트워크" 를 허용했는지 |
| 어제는 됐는데 오늘 안 됨 | 공유기가 IP를 바꿨을 수 있어요. **폰 연결** 을 눌러 QR을 다시 찍으세요 |
| 태블릿에 exe 설치가 안 됨 | 정상이에요. exe는 컴퓨터용이에요. 태블릿은 위 방법으로 주소를 열어주세요 |

주소가 자꾸 바뀌어서 번거로우면 공유기에서 그 컴퓨터에 **고정 IP**를 주면 계속 같은 주소를 쓸 수 있어요.

## 4. 백업과 복구

### 자동 백업

프로그램을 **켤 때마다** 예약 데이터를 자동으로 백업해요. 최근 30개까지 보관해요.

기본 백업 폴더:
```
C:\Users\<사용자>\AppData\Roaming\yeyakbo\backups
```

**설정 > 백업** 에서 폴더를 바꿀 수 있어요. **OneDrive 폴더로 지정하면** 클라우드에도 자동으로
올라가서, 컴퓨터가 고장 나도 예약 기록이 남아요. (추천)

지금 바로 백업하려면 상단 메뉴 **파일 > 지금 백업하기** (`Ctrl+B`)

### 데이터 위치

```
C:\Users\<사용자>\AppData\Roaming\yeyakbo\data.db
```

이 파일 하나에 모든 예약이 들어 있어요. 상단 메뉴 **도움말 > 프로그램 정보** 에서도 확인할 수 있어요.

### 새 버전으로 바꿀 때

**예약 데이터를 옮기거나 백업을 적용할 필요가 없어요.** 새 설치파일만 실행하면 돼요.

예약 데이터는 프로그램이 설치된 폴더가 아니라 **별도 데이터 폴더**에 있어서, 프로그램만 새 것으로
바뀌고 데이터는 건드리지 않아요. 프로그램을 지웠다 다시 설치해도 예약은 남아요.

| 항목 | 새 버전 설치 후 |
|---|---|
| 저장한 예약 | 그대로 유지 |
| 타석 수 · 영업시간 · 소요시간 규칙 | 그대로 유지 |
| PIN | 그대로 유지 (폰도 다시 입력할 필요 없어요) |
| 백업 파일들 | 그대로 유지 |

순서

1. 마음 편하게 하려면 먼저 **파일 > 지금 백업하기** (`Ctrl+B`) 한 번 눌러두세요
2. 새 설치파일을 실행해요
3. 설치 중에 "예약보드를 닫아달라"는 안내가 나오면 닫아주세요 (프로그램이 하나만 실행되도록 되어 있어요)
4. 설치가 끝나고 실행하면 예약이 그대로 있어요
5. 확인하려면 상단 메뉴 **도움말 > 프로그램 정보** 에서 버전을 보세요

### 컴퓨터를 바꾸거나 데이터를 되살릴 때

1. 새 컴퓨터에 예약보드를 설치하고 **한 번 실행한 뒤 완전히 종료**해요
2. `C:\Users\<사용자>\AppData\Roaming\yeyakbo` 폴더를 열어요
   (탐색기 주소창에 `%APPDATA%\yeyakbo` 를 붙여넣으면 바로 열려요)
3. 백업 파일(`예약보드-20260818-1432.db`)을 그 폴더에 복사하고 이름을 **`data.db`** 로 바꿔요
4. 같은 폴더에 `data.db-wal`, `data.db-shm` 파일이 있으면 **삭제**해요 (중요)
5. 예약보드를 다시 실행하면 예약이 복구돼요

## 5. 문제가 생기면

| 증상 | 해결 |
|---|---|
| 창이 하얗게만 보여요 | 상단 메뉴 **보기 > 새로고침** |
| 프로그램이 두 번 실행되지 않아요 | 정상이에요. 데이터가 갈리지 않게 하나만 뜨도록 만들었어요 |
| 글씨가 너무 작아요 | **보기 > 확대** (`Ctrl +`) |
| 예약판이 가로로 너무 길어요 | 예약판 오른쪽 위 **−** 버튼으로 줄이세요 |
| "다른 프로그램이 포트를 쓰고 있어요" | 컴퓨터를 다시 시작한 뒤 예약보드를 먼저 실행하세요 |
| 예약이 저장이 안 돼요 | 겹치는 자리인지 확인하세요. 이유를 화면에 적어줘요 |
| PIN을 잊었어요 | 카운터 컴퓨터에서 재설정할 수 있어요. **PIN_안내.md** 참고 |
| 소요시간이 실제와 달라요 | **설정 > 소요시간 규칙** 에서 인원별 시간을 고치세요 |

### 소요시간 규칙 손보기

기본값은 **1인 1게임 30분** 이에요. 이 값이면

| 인원 | 2게임 소요 |
|---|---|
| 1명 | 1시간 |
| 2명 | 2시간 |
| 3명 | 3시간 |
| 4명 | 4시간 |
| 6명 | 6시간 |

인원이 많을 때 실제로는 더 빨리 끝난다면, **설정 > 소요시간 규칙** 에서 그 인원의 시간을 줄이세요.
예를 들어 6명을 15분으로 바꾸면 6명 2게임이 3시간으로 계산돼요.

2주쯤 실제 종료 시각을 적어보고 맞춰가는 걸 권해요. 개별 예약은 **+30분 / -30분** 으로 그때그때
조정할 수 있어요.

## 6. 알아두면 좋은 것

- 폰·태블릿은 **아이폰(iOS)과 안드로이드 모두** 됩니다. 앱을 설치하지 않고 브라우저로 열어요
- 인터넷이 끊겨도 예약보드는 그대로 동작해요. 매장 안에서만 통신해요
- 예약 데이터는 카운터 컴퓨터 밖으로 나가지 않아요
- 손님 연락처가 들어 있으니 컴퓨터에 **잠금 화면**을 걸어두는 걸 권해요
- 지난 예약은 1년이 지나면 자동으로 지워져요 (설정에서 기간 변경 가능)
- 프로그램을 새 버전으로 바꿀 때는 새 설치파일을 그냥 실행하면 돼요. 예약·설정·PIN 모두 그대로 남아요
