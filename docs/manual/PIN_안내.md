# PIN(잠금번호) 안내

예약보드에서 PIN이 왜 필요하고, 어떻게 정하고 관리하는지 정리했어요.

---

## PIN이 왜 필요한가

폰·태블릿에서 예약판을 보려면 매장 와이파이를 통해 카운터 컴퓨터에 접속해요.
그런데 **손님도 같은 와이파이를 쓰기 때문에**, 주소를 아는 사람은 누구나 접속을 시도할 수 있어요.
예약판에는 손님 이름과 연락처가 들어 있으니 잠금이 필요해요.

```
[카운터 컴퓨터]  ← 예약 데이터 원본
      │
   매장 와이파이 (손님도 함께 사용)
      │
  ┌───┴────┬─────────┐
[직원 폰] [태블릿]  [손님 폰]  ← 주소를 알면 접속 시도 가능
   PIN ✓    PIN ✓     PIN ✗ 막힘
```

- **카운터 컴퓨터에서는 PIN을 묻지 않아요.** 그 앞에 있는 사람은 이미 컴퓨터를 쓸 수 있는 사람이니까요
- **폰·태블릿에서는 접속할 때마다 PIN**을 확인해요 (한 번 넣으면 그 기기는 기억해요)

---

## 처음 정하기

프로그램을 처음 켜면 PIN 설정 화면이 나와요. 두 번 입력하면 끝이에요.

### 규칙

| 조건 | 설명 |
|---|---|
| 숫자 4~8자리 | 4자리를 권해요 |
| `0000`, `7777` 처럼 같은 숫자 반복 | 사용할 수 없어요 |
| `1234`, `4321` 처럼 연속된 숫자 | 사용할 수 없어요 |

### 정할 때 팁

- 매장 전화 뒷자리, 매장 번지수처럼 **직원은 아는데 손님은 모르는** 숫자가 좋아요
- 도어락이나 금고와 **같은 번호는 피하세요**
- 카운터에 적어서 붙여두지 마세요. 손님이 볼 수 있는 자리면 잠금 의미가 없어져요

---

## 직원들에게 알려주기

1. 새로 온 직원에게는 **말로** 알려주는 게 가장 안전해요
2. 단체 대화방에 올리는 건 피해주세요. 나중에 그만둔 직원 폰에도 계속 남아요
3. 직원이 그만두면 **PIN을 바꾸고** 기존 기기 접속을 끊어주세요 (아래 참고)

---

## 폰 · 태블릿에서 쓰는 법

1. 폰이 **매장 와이파이**에 붙어 있는지 확인
2. 브라우저 주소창에 접속 주소 입력 (예: `http://192.168.0.10:5180`)
   - 주소는 컴퓨터의 **설정 탭** 또는 상단 메뉴 **도움말 > 폰·태블릿 접속 주소** 에서 확인
3. PIN 입력 → 예약판 열림
4. 한 번 입력하면 그 기기는 기억해요. 매번 넣지 않아도 돼요
5. 홈 화면에 추가해두면 앱처럼 열려요

---

## 여러 번 틀렸을 때

장난이나 무작위 시도를 막기 위해 잠시 잠겨요.

| 틀린 횟수 | 잠김 시간 |
|---|---|
| 5번 | 1분 |
| 10번 | 5분 |
| 15번 | 30분 |

기다렸다가 다시 입력하면 돼요. 카운터 컴퓨터는 이 제한과 관계없이 계속 쓸 수 있어요.

---

## PIN 바꾸기

**카운터 컴퓨터에서만** 바꿀 수 있어요. (폰에서 남이 몰래 바꾸는 걸 막기 위한 장치예요)

```
설정 탭 → 폰·태블릿 접속과 PIN → [PIN 변경]
→ 새 PIN 두 번 입력 → [바꾸기]
```

바꾸면 **지금 연결된 폰·태블릿은 모두 접속이 끊겨요.** 각자 새 PIN을 한 번 넣으면 다시 쓸 수 있어요.

---

## PIN을 잊어버렸을 때

카운터 컴퓨터에서 **현재 PIN 없이** 새로 정할 수 있어요. 컴퓨터 앞에 있는 사람은 이미 예약 데이터를
볼 수 있는 사람이라, 여기서 옛 PIN을 다시 묻는 건 의미가 없기 때문이에요.

- 예약판이 열리는 경우: **설정 탭 → PIN 변경** → 새 PIN 두 번 입력
- PIN 화면이 떠서 못 들어가는 경우: 화면 아래 **PIN을 잊었어요 (이 컴퓨터에서 재설정)** 버튼

폰이나 태블릿에서는 이 방법이 통하지 않아요. 반드시 카운터 컴퓨터에서 해주세요.

---

## 기기 접속 끊기

태블릿을 잃어버렸거나 직원이 그만뒀을 때 씁니다.

```
설정 탭 → 폰·태블릿 접속과 PIN → [모든 기기 접속 끊기]
```

연결된 모든 폰·태블릿이 로그아웃돼요. 계속 쓸 기기는 PIN을 다시 넣으면 돼요.
더 확실하게 하려면 **PIN도 함께 바꿔주세요.**

같은 화면에서 지금 몇 대가 연결되어 있는지도 볼 수 있어요. 직원 수보다 많으면 한 번 끊고
PIN을 바꾸는 게 좋아요.

---

## 카운터 컴퓨터에서도 PIN을 묻게 하려면

카운터가 손님 눈에 그대로 보이는 자리라면 이 설정을 켜세요.

```
설정 탭 → 폰·태블릿 접속과 PIN → ☑ 이 컴퓨터에서도 PIN 요구하기
```

켜면 프로그램을 열 때마다 PIN을 넣어야 해요. 전화 응대가 잦으면 번거로울 수 있으니
필요할 때만 쓰세요. (이 상태에서 PIN을 잊어도 PIN 화면의 **재설정** 버튼으로 풀 수 있어요.)

---

## 참고: 알아두면 좋은 한계

- 매장 와이파이 안에서 오가는 통신은 암호화되어 있지 않아요. 예약보드는 인증서 없이 동작하는
  매장 내부 프로그램이라, PIN 자체는 같은 와이파이에서 통신을 들여다볼 수 있는 사람에게는
  노출될 수 있어요. 실제로 그러려면 매장 와이파이 비밀번호를 알고 전문 도구를 써야 하니
  현실적인 위험은 낮지만, **은행 비밀번호처럼 중요한 번호는 PIN으로 쓰지 마세요.**
- 와이파이 비밀번호를 손님에게 공개하고 있다면, 직원용 와이파이를 따로 두는 게 가장 확실한 방법이에요.
