# 폰 · 태블릿에서 예약보드 보기

직원용 · 1장 안내

> ## ⚠ 설치할 파일이 없어요
>
> 카톡으로 받은 **설치파일(`.exe`)은 카운터 컴퓨터에만 쓰는 거예요.**
> 폰과 태블릿에는 설치되지 않아요. 앱스토어·플레이스토어에서 받을 것도 없어요.
>
> **주소를 한 번 열면 끝이에요.** 아이폰·안드로이드 모두 같은 방법이에요.

---

## 먼저 확인할 것 두 가지

1. 폰·태블릿이 **매장 와이파이**에 연결되어 있어야 해요 (LTE·5G로 잡혀 있으면 안 열려요)
2. **카운터 컴퓨터가 켜져 있고 예약보드가 실행 중**이어야 해요 (예약 내용이 그 컴퓨터에 있어요)

---

## 방법 1. QR 코드 찍기 (제일 쉬워요)

```
[카운터 컴퓨터]                          [내 폰]
 예약보드 실행
      ↓
 오른쪽 위 [폰 연결] 버튼 누르기
      ↓
 화면에 QR 코드가 크게 나옴    ──찍기──▶  카메라 앱으로 QR 찍기
                                              ↓
                                        뜨는 주소 누르기
                                              ↓
                                          PIN 입력 → 끝
```

1. 카운터 컴퓨터에서 예약보드 오른쪽 위 **폰 연결** 버튼을 눌러요
2. 폰 **카메라 앱**을 열어 화면의 QR 코드를 비춰요 (아이폰·안드로이드 기본 카메라로 됩니다)
3. 화면에 뜨는 주소를 눌러요
4. **PIN 4자리**를 넣으면 예약판이 열려요

## 방법 2. 주소를 직접 입력하기

카운터 컴퓨터의 **폰 연결** 창이나 **설정** 탭에 접속 주소가 적혀 있어요.
`http://192.168.0.10:5180` 처럼 생긴 주소예요. 폰 브라우저 주소창에 그대로 입력하면 돼요.

숫자와 점, 콜론(`:`)까지 똑같이 입력해야 해요. 검색창이 아니라 **주소창**에 넣어주세요.

---

## 홈 화면에 앱처럼 두기 (한 번만 하면 돼요)

이걸 해두면 다음부터는 아이콘 한 번 눌러서 바로 열려요. 주소창도 안 보여서 앱처럼 느껴져요.

### 아이폰 · 아이패드

**반드시 사파리로 열어야 해요.** (크롬에서는 이 기능이 없어요)

1. 사파리로 예약보드를 열어요
2. 화면 아래쪽 **공유 버튼** (□ 안에 ↑ 있는 모양)을 눌러요
3. 목록을 아래로 내려서 **홈 화면에 추가** 를 눌러요
4. 이름이 `예약보드` 로 나오면 오른쪽 위 **추가**

### 안드로이드

1. **크롬**으로 예약보드를 열어요
2. 오른쪽 위 **⋮** (점 세 개)를 눌러요
3. **홈 화면에 추가** 또는 **앱 설치** 를 눌러요
4. **설치** 또는 **추가**

---

## 이렇게 쓰면 돼요

| 화면 | 하는 일 |
|---|---|
| **시간표** | 시간대별로 남은 타석 수 보기. 시간을 누르면 그 시간으로 예약 등록 |
| **예약 목록** | 오늘 예약 전체 보기. 손님이 오면 **체크인**, 끝나면 **완료** |
| **찾기** | 이름이나 전화 뒷자리로 예약 찾기 |
| 오른쪽 아래 **+ 예약** | 새 예약 등록 (시간 → 인원 → 게임 수만 누르면 끝) |

카운터 컴퓨터와 **같은 예약판**을 봐요. 폰에서 예약을 잡으면 카운터 화면에도 바로 나타나요.

---

## 안 열릴 때

| 증상 | 확인 |
|---|---|
| 페이지가 안 열려요 | 폰이 매장 와이파이에 붙어 있나요? 와이파이 아이콘 확인 |
| 그래도 안 열려요 | 카운터 컴퓨터가 켜져 있고 예약보드가 실행 중인가요? |
| 어제는 됐는데 오늘 안 돼요 | 접속 주소가 바뀌었을 수 있어요. 카운터에서 **폰 연결** 눌러 QR을 다시 찍어주세요 |
| PIN이 안 맞아요 | 5번 틀리면 1분간 잠겨요. 잠시 기다린 뒤 다시 넣어주세요 |
| "안전하지 않은 연결" 이라고 나와요 | 매장 안에서만 쓰는 주소라 정상이에요. 그냥 계속 진행하면 돼요 |
| 아이폰에서 홈 화면 추가가 안 보여요 | 크롬이 아니라 **사파리**로 열어주세요 |

---

## 알아두면 좋은 것

- 데이터 요금이 들지 않아요. 매장 와이파이 안에서만 통신해요
- 오래(1~2주) 안 열면 PIN을 다시 물어볼 수 있어요. 한 번 넣으면 다시 기억해요
- PIN은 매장 밖에서 공유하지 말아주세요. 손님 연락처가 들어 있어요
